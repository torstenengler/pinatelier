# Pin Atelier

Statische Startseite für Pin Atelier — bereit für Cloudflare Pages.

## Cloudflare Pages Einstellungen

- **Production branch:** `main`
- **Build command:** leer lassen
- **Build output directory:** `/`
- **Root directory:** leer lassen

Die Seite nutzt keine Build-Schritte und kann direkt aus diesem Repository veröffentlicht werden.

## Vor dem Launch

1. Instagram-URL in `index.html` prüfen und ggf. anpassen.
2. Rechtliche Seiten (Impressum, Datenschutz) ergänzen.
3. Eigene Produktbilder und Shop-Links ergänzen.
4. In Cloudflare Pages die Custom Domain verbinden.
